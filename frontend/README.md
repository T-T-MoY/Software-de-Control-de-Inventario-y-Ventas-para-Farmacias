# Frontend — Sistema de Farmacia

Aplicación Vue 3 para el Sistema de Control de Inventario y Ventas para Farmacias. La plantilla implementa acceso y administración de usuarios; los módulos restantes se muestran como pendientes en la navegación.

```sh
npm install
npm run dev
npm run build
```

La API local se configura con `VITE_API_URL` (por defecto `http://localhost:3000`). En Docker Compose, la aplicación está disponible en <http://localhost:5173>.
